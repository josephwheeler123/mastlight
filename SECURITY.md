# Security

If you think you have found a security problem in Mastlight, please email **hello@mastlight.io** instead of opening a public issue. Say which version you have, whether you are on a Mac or Windows, and what you saw. Leave out real credentials, tokens and private conversation text.

Mastlight's source is not public, so there is no code to send a pull request against; a clear description of what happens and how to reproduce it is what helps most.

Only the newest release is supported: this is an early preview, and fixes ship as a new version.

What Mastlight does and does not touch (no account, no server of ours, never sees a Claude credential) is described in the README under Privacy.
