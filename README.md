# Mastlight

A Mac app for people who keep a lot of Claude Code sessions going at once. Every session tells you what it needs, and you answer it in one place.

This repository holds **release downloads only**. Getting started: **https://mastlight.io/start**

- Requires a Mac with Apple silicon, Claude Code 2.1.85 or newer, and a Claude subscription.
- Early preview. The app is not signed by Apple yet, so macOS asks you to confirm the first launch (the getting-started page shows how).
